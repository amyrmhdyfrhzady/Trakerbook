این کتاب یک دوره کوتاه‌مدت نیست. یک برنامه رشد چندساله است که نقطه شروع آن یک پروژه‌ساز AI-assisted با تجربه عملی زیاد و مبانی مهندسی هنوز در حال شکل‌گیری است، و نقطه هدف آن آمادگی حرفه‌ای برای رقابت در موقعیت‌های مهندسی نرم‌افزار در شرکت‌هایی مانند Apple است.

درباره این کتاب

این کتاب برای یک نیاز مشخص نوشته شده است:

چگونه کسی که امروز با کمک شدید AI پروژه‌های واقعی می‌سازد، طی چند سال به یک Software Engineer مستقل، عمیق و حرفه‌ای تبدیل شود؟

این کتاب قرار نیست فقط فهرستی از تکنولوژی‌ها باشد.

چرخه یادگیری کتاب:

Learn → See → Try → Fail → Debug → Solve → Build → Review

یعنی:

یاد بگیر → ببین → امتحان کن → اشتباه کن → اشکال‌زدایی کن → حل کن → بساز → مرور کن

در این مسیر:

  • پروژه‌های واقعی حفظ می‌شوند و به سرمایه آموزشی تبدیل می‌شوند.
  • استفاده از AI حذف نمی‌شود؛ بلکه از «جایگزین فکر» به «ابزار افزایش بهره‌وری مهندس» تبدیل می‌شود.
  • مبانی JavaScript و Computer Science قربانی سرعت نمی‌شوند.
  • Frontend تخصص اصلی باقی می‌ماند.
  • Backend، Systems و Cloud به‌اندازه‌ای یاد گرفته می‌شوند که یک Frontend Engineer بتواند کل سیستم را بفهمد.
  • Technical English از روز اول همراه آموزش خواهد بود.
  • هر بخش با تمرین، Debugging و ارزیابی همراه است.

اصل مهم

مثال

  • API چیست؟

  • database transaction چیست؟
  • cron چه محدودیتی دارد؟
  • race condition چیست؟

این‌ها لایه دوم مهارت‌اند.

پیش‌نیاز

فصول 1 و 2.

مفهوم: Variables

let age = 17;
const name = "Amir";

let برای مقدار قابل‌تغییر و const برای bindingی است که قرار نیست دوباره assign شود.

چرا مهم است؟

تمام الگوریتم‌های بعدی بر نگهداری state تکیه می‌کنند.

مثال

let count = 0;

count = count + 1;

console.log(count);

توضیح

  • count = 0 مقدار اولیه است.
  • count + 1 مقدار جدید را محاسبه می‌کند.
  • assignment مقدار جدید را نگه می‌دارد.

Conditions

if (age >= 18) {
  console.log("Adult");
}

Loops

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}

Arrays

باید تفاوت این دو را حفظ کنی:

i          = index
numbers[i] = value at that index

Objects

let user = {
  name: "Amir",
  age: 17
};

console.log(user.name);

Functions

function add(a, b) {
  return a + b;
}

console.log(add(5, 3));

🧪 امتحانش کن

در مثال بالا:

  • a و b را عوض نکن.
  • مقدار arguments را تغییر بده.
  • قبل از اجرا خروجی را حدس بزن.

🐛 خطاهای رایج

خطا 1

if (numbers[i] = 25) {
}

مشکل: assignment به‌جای comparison.

اصلاح:

if (numbers[i] === 25) {
}

خطا 2

for (let i = 0; i < numbers.length;) {
}

اگر i تغییر نکند، loop ممکن است متوقف نشود.

خطا 3

console.log(number[i]);

در حالی که متغیر numbers است.

فصل 4 — Array و Object Thinking

اهداف یادگیری

  • مفاهیم اصلی «Array و Object Thinking» را با زبان خودت توضیح بدهی.
  • یک مثال واقعی مرتبط با «Array و Object Thinking» را تحلیل یا پیاده‌سازی کنی.
  • خطاهای رایج و trade-offهای مرتبط با «Array و Object Thinking» را تشخیص بدهی.

پیش‌نیاز

فصل‌های قبلی بخش Programming Foundation و توانایی نوشتن JavaScript ساده.

اهداف

  • آرایه‌ای از objectها را بخوانی.
  • property را درست استخراج کنی.
  • داده را filter و count کنی.
  • حذف و جابه‌جایی را بفهمی.

مثال

let users = [
  { name: "Amir", age: 17 },
  { name: "Ali", age: 20 },
  { name: "Sara", age: 16 }
];

for (let i = 0; i < users.length; i++) {
  if (users[i].age >= 18) {
    console.log(users[i].name);
  }
}

فکر کردن

users[i]      → object
users[i].age → property
users[i].name → output

🧪 امتحانش کن

age >= 18 را به age < 18 تغییر بده و قبل از اجرا خروجی را پیش‌بینی کن.

حذف دستی

برای حذف بدون splice:

for (let j = i; j < numbers.length - 1; j++) {
  numbers[j] = numbers[j + 1];
}

numbers.length--;

این الگوریتم از ایده «شیفت عناصر بعدی به چپ» استفاده می‌کند.

🐛 خطای رایج

numbers[j] = numbers[j++];

به‌جای:

numbers[j] = numbers[j + 1];

در expression دوم، مقدار بعدی را می‌خواهیم؛ افزایش counter را داخل access قرار نمی‌دهیم.

function sumArray(numbers) {

Closure

Closure حالتی است که function به محیط lexical بیرونی خود دسترسی را حفظ می‌کند.

function counter() {

const next = counter();

console.log(next());
console.log(next());
