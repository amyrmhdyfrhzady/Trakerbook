پیش‌نیاز

اهداف

  • آرایه‌ای از objectها را بخوانی.
  • property را درست استخراج کنی.
  • داده را filter و count کنی.
  • حذف و جابه‌جایی را بفهمی.

مثال

js

  { name: "Amir", age: 17 },
  { name: "Ali", age: 20 },
  { name: "Sara", age: 16 }

for (let i = 0; i < users.length; i++) {
  if (users[i].age >= 18) {
    console.log(users[i].name);
  }
}

فکر کردن

text

users[i].age → property
users[i].name → output

🧪 امتحانش کن

$1 را به $1 تغییر بده و قبل از اجرا خروجی را پیش‌بینی کن.

حذف دستی

برای حذف بدون $1:

js
for (let j = i; j < numbers.length - 1; j++) {
  numbers[j] = numbers[j + 1];
}

numbers.length--;

این الگوریتم از ایده «شیفت عناصر بعدی به چپ» استفاده می‌کند.

🐛 خطای رایج

js
numbers[j] = numbers[j++];

به‌جای:

js
numbers[j] = numbers[j + 1];

در expression دوم، مقدار بعدی را می‌خواهیم؛ افزایش counter را داخل access قرار نمی‌دهیم.
